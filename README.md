# 提个醒

> 给 Hana 的桌面通知加一只小喇叭：聊天回复、计划任务、巡检完成时，按你的设置弹出 Windows 通知。

## ⚠️ 先看这里

- **只支持 Windows。** 提醒使用 Windows 自带的桌面通知，其他系统不能保证正常工作。
- **提个醒会接管 Hana 自动发出的三项完成通知**：聊天回复完成、计划任务完成、巡检完成。安装后请打开 **Hana 设置 → 通知**，把这三项原版通知设为「从不」，避免同一件事弹两次。计划任务如果已经通过小花的桌面通知功能发过一条，提个醒会自动跳过重复提醒；任务自己的通知不受接管开关影响。
- **「文案润色」默认关闭。** 开启后，通知所需的短摘要会发送给你选择的模型；请求失败会自动退回本地规则版，不会让通知悄悄消失。
- 自定义音效需要你自己准备音频文件，本身不自带任何音效哈。也不会偷偷替换系统音效。

## 这是干什么的？

你切到别的窗口去做事，Hana 回复完了，桌面右下角就会冒出一条提醒。不用反复切回去看，也不用依赖小花临时想起要通知你。

原版 Hana 也有相同功能， 但只有简单的一句提示，我并不知道是哪个窗口完成了。所以我做了这个插件！

不仅可以显示哪个窗口的对话完成（通过显示对话标题的形式），还可以显示具体回复内容摘要！并且内容格式有好几种不同的风格可以选择！

另外，如果安装了【表情包】插件，还可以新增九种方言风格，以及一个【学我说话】风格～地址：https://github.com/moononnn/hanako-biaoqingbao

还可以自定义音效！所以你可以给不同的助手配置不同的音效，一耳朵就知道是哪个助手回复完成。（我给小花配了塞尔达呀哈哈的音效，莫名喜感哈哈哈）

想要文案内容显示效果更好的话建议开启文案润色功能！但是代价是提醒弹窗会有一丢丢的延迟，为了文案质量降低一点点及时性，你不会介意的，对吧？


## 它能做什么

- 💬 **聊天回复完成提醒**
  - 可以选择总是提醒、当前聊天没在看时提醒、Hana 不在前台时提醒，或完全关闭。
  - 同一个聊天窗口 30 秒内连续回复会合并，窗口结束后补一条汇总提醒；不同聊天窗口互不合并。
  - 只在最终回复完成时提醒，工具调用过程中的中间回合不会每一步都弹。
  - 通知会尽量带上对应角色的头像和会话标题，多个窗口同时开着也能分清是哪一个窗口。
- ⏱️ **弹窗停留时间**
  - 设置页可以选择「系统默认」或「停留久一些」；这是 Windows 原生通知提供的两档，不能精确填写任意秒数。
- 🗓️ **计划任务完成提醒**
  - 有独立的「接管计划任务提醒」开关，也可以设置为总是提醒、Hana 不在前台时提醒，或从不提醒。
  - 计划任务已经通过小花的桌面通知功能发过一条时，会自动跳过提个醒的重复完成提醒；为确认这一点，补弹可能会晚约 1～2 秒。
  - 这套去重只识别小花通知功能发出的桌面通知；任务自己调用其他弹窗程序时，需要自行关闭其中一侧。
- 🔎 **巡检完成提醒**
  - 和计划任务一样，可以单独设置提醒档位；成功和失败都会明确写在通知里。
- 🌙 **静默时段**
  - 设置一段时间后，所有通知都暂时安静，支持跨午夜，例如 `22:00 至 08:00`。
- 🎨 **按角色个性化**
  - 每个角色可以单独选择通知风格和音效，风格与音效可以自由组合。
  - 内置风格包括：跟随默认、简洁高效、活泼可爱、温柔贴心、闺蜜俏皮、古风书简、大厂黑话、摩斯电码、系统故障、锟斤拷。
  - 规则版风格只包装标题和正文，不改写原回复；正文仍然来自实际回复内容。
- 🔔 **自定义音效**
  - 支持 `.wav`、`.mp3`、`.m4a`、`.aac`。
  - 音效文件夹可以自己选：点「选择文件夹…」弹 Windows 原生选择框，或者手动填绝对路径，选好把音频文件放进去，点「刷新音效」就能按角色分配并试听；留空则用默认目录。
  - 也可以选择系统默认音效或静音；这些设置只影响提个醒自己的通知。
- ✍️ **可选的文案润色**
  - 对默认、简洁、活泼、温柔、闺蜜俏皮、古风书简、大厂黑话这类语气风格生效；装表情包插件后新增的方言风格和「学我说话」也走润色（方言润色版效果更地道）；摩斯、故障、锟斤拷等整活风格不会调用模型。
  - 支持跟随当前对话模型、从 Hana 已配置的模型里选择，或填写自定义 API。
  - 自定义 API 受插件 `manifest.json` 的 `network.allowedHosts` 主机名白名单限制；名单外的域名需要先加入该字段，再重启 HanaAgent，不能直接填了就用。
  - 开启后通常会多等约 1～2 秒；模型失败或超时，会自动退回规则版。
  - 设置页提供「保存配置」和「测试一下」，不会让你对着一堆配置盲猜。
- 🧰 **检查更新与反馈**
  - 设置页底部可以检查新版本。
  - 遇到问题时，可以从「反馈」入口和小花聊几句，让它把插件版本、Hana 版本和系统信息整理成 issue 草稿；你检查后再复制或提交。

## 安装

1. 下载 Release 里的插件 zip 安装包。
2. 按 Hana 的插件安装方式导入并启用「提个醒」。
3. 重启 Hana，让桌面通知监听正式接上。
4. 打开「提个醒」页面，按需要调整三项提醒档位、弹窗停留时间、计划任务接管开关、静默时段、角色风格和音效。
5. 如果不想重复弹窗，记得把 Hana 原版的三项通知设为「从不」；计划任务通过小花通知功能发出的桌面通知不受这个开关影响。

默认配置已经可以直接工作：聊天回复默认在你没有看当前聊天时提醒，计划任务和巡检默认在 Hana 不在前台时提醒。

## 卸载

在 Hana 的插件管理中禁用或卸载「提个醒」即可。插件代码不会修改小花的身份或性格文件。

如果你还想清理设置和自定义音效，请在确认不再需要后，再删除插件数据目录；卸载插件本身不会替你擅自删除这些个人数据。

## 反馈

优先使用 Hana 页面底部「关于提个醒」里的「反馈」入口。提 issue 时，尽量附上：

- 提个醒版本
- Hana 版本和 Windows 版本
- 具体操作步骤
- 实际现象与预期现象
- 能复现时附一张截图或相关日志片段

> **GitHub Issues：** https://github.com/moononnn/Hanako-tigexing/issues

## 隐私

- 普通规则版通知在本机处理，不需要网络，也不会把回复内容上传到外部服务。
- 开启「文案润色」后，只会把生成通知所需的角色名、通知类型、短摘要和所选风格交给模型，用来生成标题和正文；完整聊天记录不会因为这项功能自动发送。
- 如果选择自定义 API，API 地址和 Key 只在你主动配置并测试/使用对应功能时生效。Windows 下 Key 优先使用系统 DPAPI 加密保存；如果系统加密不可用，设置页会提示实际存储状态。
- 「检查更新」只在你主动点击时访问 GitHub。
- 「反馈」只在你主动打开并发送反馈后调用模型；反馈草稿提交到 GitHub 前会先显示给你检查。
- 设置、音效分配和自定义音频都保存在本机插件数据目录，不会打包进发布安装包。

## 兼容性

- Windows 10 / 11
- 需要支持插件页面、运行时监听和桌面通知的 Hana 版本
- 不需要 Python、C# helper 或其他额外运行时依赖
